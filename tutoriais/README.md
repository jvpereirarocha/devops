# Tutoriais

Passo a passo das mudanças feitas no cluster k3s do homelab: criação de novos serviços,
alterações em serviços existentes e configurações do cluster. Cada tutorial explica
**o que** foi feito, **como** reproduzir e **por que** cada decisão técnica foi tomada.

Os valores específicos do ambiente (IPs, domínios internos, senhas e tokens) aparecem como
placeholders, por exemplo `<IP_DO_LOADBALANCER>` ou `argocd.<seu-dominio-local>`.
Substitua pelos valores do seu ambiente.

Os problemas encontrados pelo caminho ficam registrados em [`../troubleshooting/`](../troubleshooting/).
